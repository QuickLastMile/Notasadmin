Estados definidos:
- Disponible

- Buscando

- Atención
- Alerta
- Completado
- Sugerencia
- Falta información
- Gracias

Nota: los archivos visuales actuales son recortes de una guía visual generada. Para producción conviene generar/exportar cada asset de forma independiente, preferiblemente en PNG con fondo transparente y tamaños exactos (512x512, 256x256, 128x128 y 64x64 según el uso).
